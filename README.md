## English

Mini is a Windows-based virtual operating system.  
We guarantee user freedom with maximum support and minimal interference.

### Why Mini?
* **Security and transparency:** The source code is open, so you can use it with confidence.
* **Powerful and easy GUI:** A sleek interface allows anyone to use the virtual OS environment effortlessly.
* User-Centered Customization: Freely configure the entire system, including keyboard remapping, process management, notification settings, and keylogger protection.

### Development Stack
* **Language:** C#
* **Framework:** .NET / WPF (Windows Presentation Foundation)
* **API:** Win32 API, WinRT Notification Listener

### Installation and Execution Instructions
1. Download the latest file from [here](https://github.com/minty-developer/Mini/releases/latest).
2. Run the downloaded file and follow the on-screen instructions to install and launch it.

* **안전하고 투명함:** 소스 코드가 공개되어 있어 안심하고 사용할 수 있습니다.
* **강력하고 쉬운 GUI:** 세련된 인터페이스로 누구나 쉽게 가상 OS 환경을 이용할 수 있습니다.
* **사용자 중심 커스텀:** 키보드 리매핑, 프로세스 정리, 알림 관리, 키로거 방어 등 시스템 전반을 자유롭게 설정할 수 있습니다.
